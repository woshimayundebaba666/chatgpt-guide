使用 ChatGPT 时，我强烈建议你用 **自己的 Google 账号**登录。这样账号、聊天记录、订阅和找回方式都掌握在自己手里，不需要去淘宝购买来历不明的账号。

{% success 我的推荐 open %}
**自己的 Google 账号 + ChatGPT 官方登录**，是最省心的使用方式。普通用户直接使用 ChatGPT 或 Codex 即可，不需要为了日常聊天另外配置 API。
{% endsuccess %}

## 一、准备自己的 Google 账号

如果已经有 Google 账号，打开 ChatGPT 后选择“使用 Google 账号继续”，按照页面提示完成登录即可。

如果还没有 Google 账号，可以先注册一个。我的实际做法是：在注册 Google 账号时使用 **QQ 邮箱作为现有邮箱**，注册成功后，这个 Google 账号同样可以登录 ChatGPT。注册页面是否提供这一选项，以当时显示的界面为准。

![使用以 QQ 邮箱注册的 Google 账号登录后，账号显示为 Pro](/account/images/qq-google-login.png)

{% warning 不要购买账号 open %}
不要在淘宝或其他非官方渠道购买 ChatGPT、Google 或所谓“共享 Pro”账号。购买的账号可能被原主人找回，也可能多人共用，聊天记录、文件和付款信息都存在泄露风险。

无论谁以“代升级”或“客服”的名义联系你，都不要提供 Google、QQ 或 ChatGPT 密码、短信验证码、两步验证代码、恢复码、浏览器 Cookie、登录二维码或远程控制权限。
{% endwarning %}

## 二、普通使用不需要 API

OpenAI 官方同时支持“使用 ChatGPT 账号登录”和“使用 API Key”两种方式，但它们的用途和计费是分开的：

- **ChatGPT 账号登录**：适合在 ChatGPT 和 Codex 中聊天、写作与完成日常任务。
- **API Key**：适合开发程序、自动化脚本和服务器调用，通常按使用量单独计费。

API 本身是 OpenAI 提供的正规功能，并不是不能使用；只是对大多数普通用户来说没有必要。不要从他人手里购买或共享 API Key，也不要把自己的 Key 发给任何人。

## 三、升级 ChatGPT 服务

### 方案一：优先使用 OpenAI 官方升级入口

先登录自己的 ChatGPT 账号，在头像或“设置”中找到套餐与升级入口，确认套餐名称、价格、扣款周期和续费方式后再付款。官方入口能减少账号交接、隐私泄露和售后不清楚的问题。

## 四、额度用完后怎么办

“使用额度”和“每月订阅”不是一回事。Codex 的可用量会受模型、任务复杂度和时间窗口影响；达到当前使用上限时，通常先查看提示中的恢复时间，等待额度刷新，或者在官方页面查看是否可以购买额外额度或升级套餐。**不要因为临时达到上限就马上重复购买一份新订阅。**

建议按这个顺序检查：

1. 看清提示写的是“额度暂时用完”“套餐到期”，还是“付款失败”。
2. 打开 ChatGPT 的设置与套餐页面，确认当前套餐和下一次扣款日期。
3. 回忆原来的服务是在 ChatGPT 官网、手机应用商店，还是第三方平台购买的。
4. 只有确认旧服务已经到期或不会继续扣款后，再决定是否购买新服务。

## 五、更换服务前停用旧服务

如果旧订阅仍在自动续费，而你准备换一种购买方式，应该先在 **原付款平台**关闭旧订阅的自动续费，避免两边重复扣款：

- 在 ChatGPT 官网购买：从 ChatGPT 的设置与套餐管理入口检查。
- 在 Apple App Store、Google Play 等平台购买：回到对应商店的订阅管理中检查。
- 在 WildAI 等第三方购买：进入该平台的“My Subscriptions / 我的订阅”或联系其官方客服确认。

这里只需要取消续费，**不要误删 ChatGPT 或 Google 账号**。取消后还能使用多久，以套餐管理页面显示的到期时间为准。

如果分不清自己的订阅来自哪里，可以把不含姓名、邮箱、订单号和付款信息的页面截图发给 ChatGPT，并这样问：

> 请帮我判断这份 ChatGPT 服务是从哪个平台订阅的，以及应该去哪里关闭自动续费。请只指导我操作，不要让我提供密码、验证码、Cookie、恢复码或远程控制权限。

{% note 完成检查 %}
最终应确认三件事：登录的是自己的账号；当前套餐与扣款日期看得懂；更换服务时旧订阅不会继续自动扣款。
{% endnote %}
