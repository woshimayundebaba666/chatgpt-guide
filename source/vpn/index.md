如果你需要一个价格合适、日常使用稳定的节点服务，我目前使用的是 **“赔钱机场”**。我主要用它连接国外游戏、运行在线模型和观看视频，实际使用下来比较稳定；价格也不高，大约一顿饭的钱就能购买一个月的节点服务，对日常使用来说很划算。

{% warning 购买前必须知道 open %}
“赔钱机场”的网站本身需要先连接一个可用的国外节点才能访问。也就是说，你需要“先有能用的网络，才能进去购买或续费网络服务”。

**不要等服务完全到期后再续费。** 建议提前几天登录网站完成续费，否则旧节点失效后，你可能无法再次打开购买页面。可以在手机日历里设置一个到期前 3～5 天的提醒。
{% endwarning %}

## 我为什么选择它

### 稳定

我用它玩国外的游戏、运行在线模型以及观看视频，连接表现一直比较稳定。对需要长时间保持连接的使用场景来说，稳定性比单纯追求峰值速度更重要。

### 实惠

一个月的节点服务大约是一顿饭的价格。对个人日常使用而言，这个成本不高，也省去了频繁更换服务的麻烦。

{% note 体验说明 %}
以上是我的个人使用感受。网络质量仍可能受地区、运营商、设备和所选节点影响，购买时请以网站展示的套餐、流量和有效期为准。
{% endnote %}

## 购买和使用流程

### 1. 打开网站并选择套餐

先连接一个当前可用的国外节点，再点击上方按钮进入“赔钱机场”。注册或登录后，根据自己的流量和使用时间选择套餐并完成购买。

### 2. 准备 Clash 客户端

进入网站的客户端或教程页面，选择适合自己设备的 Clash 客户端。Windows 用户可以选择页面中展示的 **Clash Verge Rev**，然后下载并安装。

![在赔钱机场的客户端下载页面选择 Clash Verge Rev](/vpn/images/clash-download.png)

### 3. 把节点导入 Clash

购买完成后，在用户首页找到“手动导入客户端”区域。将网站提供的 **配置文件导入 Clash**；如果套餐提供的是订阅链接，也可以复制该链接，然后在 Clash 的订阅或配置页面添加。

![在用户首页获取订阅并导入 Clash，敏感订阅信息已隐藏](/vpn/images/subscription-import-safe.png)

{% warning 请勿分享订阅信息 open %}
配置文件、订阅链接和二维码都可能包含你的个人访问凭证。不要发给其他人，也不要把未遮挡的截图上传到公开平台。
{% endwarning %}

### 4. 选择节点并开启连接

导入成功后，在 Clash 中更新配置并选择一个可用节点，再开启系统代理。随后用浏览器打开一个国外网站测试；如果无法访问，可以切换其他节点后重试。

## 续费提醒

建议购买后立刻记下服务到期日，并设置提前提醒。我的习惯是在到期前 **3～5 天**进入网站续费，确保手里始终还有一个能打开续费页面的可用节点。

{% success 完成 %}
能正常打开国外网站，就说明节点已经成功导入并连接。以后更换套餐或续费时，记得在 Clash 中更新一次订阅或重新导入最新配置。
{% endsuccess %}
